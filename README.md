A program that writes one original fortune-cookie line for a software developer to /output/entry.txt: "Legacy code is a letter from a past you who trusted future you too much." One line, 72 characters, for make.fun's Fortune Cookie Wisdom for Developers bounty, where a judge model playing a tired senior engineer compares entries two at a time on fortune-cookie fit, truth about a developer's day, freshness of the turn, and a quiet twist that rewards a second read.

## Run it

```sh
node main.ts
```
